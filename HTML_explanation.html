How to Create a Website using HTML & CSS

A compact, beginner-friendly example you can open and tinker with right now.

Quick concept

A website is a collection of HTML elements (the structure) styled by CSS (appearance).

Example snippet

<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <title>Simple page</title>
    <style>
      body { font-family: system-ui; padding:20px; }
      .btn { background:#2563eb; color:white; padding:8px 12px; border-radius:8px; }
    </style>
  </head>
  <body>
    <h1>Hello!</h1>
    <button class="btn">Click</button>
  </body>
</html>

Tip: Move CSS into a separate file (like this one uses) to keep code clean.
