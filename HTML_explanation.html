How to Create a Website using HTML & CSS

This is a website. You can put anything you want in this. Such as Edgar Allen Poe.

What is a Website?

A website is a collection of HTML elements styled by CSS. HTML creates the structure of the website, and CSS makes it look good.

Start with 

<!doctype html>
Always start and close with the <html> tag. Next add
<html lang="en">
Those two elements are essential for all HTML pages.

The <head> tag represents a collection a metadata for the document:

<head>

The <meta charset> defines the character set for the document. uft-8 is the most commonly used character set:

<meta charset="utf-8" />

The <title> tag creates the title

<title>Simple page</title>

Place the CSS code inside of the <style></style>

<style>
      body { font-family: system-ui; padding:20px; }
      .btn { background:#2563eb; color:white; padding:8px 12px; border-radius:8px; }
</style>
This is the CSS styling. It controls what the website looks like.

The <body> tag contains all the content of an HTML document, such as text, hyperlinks, images, tables, and lists.

  <body>
    <h1>Hello World!</h1>
    <button class="btn">Click</button>
  </body>
</html>

The <h1> tag defines the most important heading. <h2> is the second most important heading, and so on.

<h1>Hello World!</h1>

The <button> tag defines a clickable button. The class attribute is used to point to a class in a style sheet.

<button class="btn">Click</button>

Always close with the </body> and </html> tags.

You should end up with:

<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <title>Simple page</title>
    <style>
      body { font-family: system-ui; padding:20px; }
      .btn { background:#2563eb; color:white; padding:8px 12px; border-radius:8px; }
    </style>
  </head>
  <body>
    <h1>Hello World!</h1>
    <button class="btn">Click</button>
  </body>
</html>
